About CSS Vars

A CSS framework built
for teams who ship

One dependency-free stylesheet, no build step, no JavaScript by default. We build the tools we wish existed when we started.

Our Mission

Make production-grade CSS accessible without the tooling overhead.

Why We Exist

Most teams don't need a build pipeline to style a website. We build a single-file framework on modern CSS — custom properties, @layer, clamp() — so any team can link one stylesheet and start shipping.

How We Work

Every component is designed reuse-first, composed from existing primitives, and tested against real client builds before it ships — from legal-tech platforms to healthcare compliance sites.

Our Values

Fast By Default

10kb minified, zero JavaScript. Performance is the default, not an afterthought.

Composable

Longhand utility axes so nothing you compose silently overrides something else.
