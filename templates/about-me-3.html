About Me

I write CSS so other
people don't have to fight it.

Kim Majali, creator of the CSS Vars Framework — a single-stylesheet system built for developers who want speed without a build pipeline.

Where it started

I spent years shipping projects on top of frameworks that shipped ten times more CSS than any single page ever used. CSS Vars started as a personal experiment to see how much could be done with custom properties alone — no preprocessor, no bundler.

Where it's going

Today the framework powers real client work — from legal-tech platforms to healthcare compliance sites — and I'm building out the accessibility layer and a Claude Skill for developer adoption next.
